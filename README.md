# Показ — предпросмотр сайта на разных устройствах

Бесплатный статический инструмент для проверки адаптивности сайта и создания наглядных композиций с ноутбуком, планшетом и телефоном. Работает прямо в браузере: не требует сборки, сервера или установки.

## Возможности

- Нейтральный стартовый макет показывает, что устройства можно перетаскивать.
- Открытие собственного сайта во встроенных экранах и прямая ссылка, если сайт запрещает встраивание.
- Настройка холста: популярные размеры или произвольные ширина и высота, внутренние поля и расстояние между устройствами.
- Однотонный, градиентный, прозрачный фон или изображение с настройкой кадрирования, положения и затемнения.
- Размеры экранов ноутбука, планшета и телефона: готовые варианты или свои значения; поворот в альбомную/портретную ориентацию.
- Перетаскивание устройств, включение и скрытие отдельных экранов.
- Сохранение композиции в браузере и создание ссылки с адресом сайта, настройками холста, видимостью и расположением устройств.
- Экспорт композиции в PNG с фоном или прозрачностью. Для снимка содержимого сайта браузер попросит разрешить захват вкладки; без захвата доступен PNG с векторными рамками устройств.

## Важно о встраивании сайтов

Некоторые сайты, включая сайты на Tilda, запрещают показ внутри iframe настройками безопасности. GitHub Pages не может снять это ограничение. Откройте такой сайт отдельно, а для демонстрации композиции используйте нейтральный макет.

Загруженное с компьютера фоновое изображение хранится в браузере. Чтобы поделиться им через ссылку, используйте небольшое изображение; для более крупных файлов укажите доступный по HTTPS URL.

## Запуск и публикация

Сборка и сервер не нужны. Главный файл — `index.html`; проект публикуется через GitHub Pages.

## SEO

Страница содержит русские метаданные, Open Graph и Twitter Card, канонический адрес, а `robots.txt` и `sitemap.xml` помогают поисковым системам индексировать сайт.
