# Показ

**Предпросмотр сайта на ноутбуке, планшете и телефоне — и презентационный PNG, который можно отправить клиенту.**

[Открыть демо →](https://ztim2008.github.io/responsive-showcase/)

«Показ» работает прямо в браузере и помогает быстро собрать наглядную композицию сайта на нескольких экранах. Без регистрации, установки и сборки.

## Как пользоваться

1. Вставьте адрес сайта и нажмите «Показать сайт».
2. Сравните версии для ноутбука, планшета и телефона. Перетаскивайте устройства, чтобы выстроить композицию, и скрывайте те, которые не нужны. Кнопка «Перезапустить демо» возвращает макет и композицию к исходному виду.
3. Выберите цвет фона или прозрачность и нажмите «Скачать PNG».

Для PNG с содержимым экранов разрешите захват и выберите вкладку с проектом. Экспорт убирает технические подписи, добавляет выразительный фон и сохраняет столько пикселей, сколько доступно в захвате. Если захват недоступен, создаётся PNG с векторными рамками устройств.

## Если сайт не открывается в рамке

Некоторые сайты запрещают встраивание через iframe. Это ограничение безопасности самого сайта; проект его не обходит. Откройте адрес отдельно, а в композиции используйте встроенный демонстрационный сайт архитектурной студии «Тёплая форма».

## О проекте

Статическая страница на HTML, CSS и JavaScript без сторонних библиотек и серверной части. Главный файл — [`index.html`](index.html). Код можно открыть локально; для полноценного PNG-захвата удобнее использовать опубликованную HTTPS-версию.

Сообщения об ошибках и предложения по улучшению можно оставить во вкладке Issues.
