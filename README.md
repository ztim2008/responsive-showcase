# Показ — предпросмотр сайта на разных устройствах

Статический инструмент для наглядного просмотра сайта в рамках ноутбука, планшета и телефона. Меняйте фон холста, перетаскивайте устройства, открывайте выбранный сайт отдельно и сохраняйте PNG-композицию.

## Возможности

- Стартовая композиция с нейтральным адаптивным демо-макетом вместо чужого сайта.
- Предпросмотр в трёх заданных размерах экрана.
- Цветной или прозрачный фон холста.
- Перемещение устройств и выбор их видимости.
- Переключение на демо-макет, если сайт запрещает встраивание, с прямой ссылкой на сайт.
- PNG-снимок выбранной вкладки браузера с текущей композицией.
- Резервный экспорт векторных рамок, если захват вкладки недоступен.
- Сохранение адреса сайта и фона в браузере.

Сайты на Tilda и других платформах могут запрещать встраивание через настройки безопасности. Статическая страница на GitHub Pages не может изменить эти настройки или проксировать чужой сайт; в таком случае откройте его отдельно, а в композиции используйте демо-макет. Для PNG с содержимым сайта разрешите захват вкладки и выберите вкладку с инструментом.

## Запуск и публикация

Сборка и сервер не нужны. Главная страница — `index.html`; проект публикуется через GitHub Pages.

## SEO

Главная страница содержит русские метаданные, Open Graph и Twitter Card, канонический адрес, а файлы `robots.txt` и `sitemap.xml` помогают поисковым системам индексировать сайт.
